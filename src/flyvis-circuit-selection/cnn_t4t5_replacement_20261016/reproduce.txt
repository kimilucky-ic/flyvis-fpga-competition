To reproduce, copy only these Python sources into a NEW sibling directory
under flyvis-circuit-selection (e.g. cnn_t4t5_reproduction_01): common.py,
cnn.py, decoder_cpu.py, prepare.py, experiment.py, audit_results.py, plots.py.
Keep accepted sibling source caches in place. Then run, strictly in order:

python -B prepare.py
python -B experiment.py train

python -B experiment.py run
python -B experiment.py analyze
python -B audit_results.py
python -B plots.py

Never execute these stages over this sealed directory. Files use exclusive
creation and attempts are preserved. If a new run fails, inspect its failure,
do not remove guards or silently retry into the same output directory.

prepare validates original identities and exact721-point maps, original R-only
API, radius7 coverage and Conv2d/patch alignment. The official CPU decoder
executes original class bodies from the pinned upstream source through AST
loading, avoiding heavy optional package initialization. No forward body is
rewritten. Checkpoint state_dict remains exact, all modules eval, inputs full
45669 states. It is compared against7 accepted GPU frames, not called FPGA proof.

train reads four historical Full trajectories ONLY for supervision. It fits
normalized H increments from23 old activity fields with a shared hex CNN,
learned own-H recurrence and offsets, without importing H node parameters or
H-target edges into the CNN. Model saved to training/cnn.pt and frozen before
test. There is no checkpoint selection using test output.

The production ClosedLoop object takes only RStepService and CNNService.
Input to each step is external brightness[721], and both services read the same
own previous full state[45669]. H has5768 outputs in TYPES order then721 hex
coordinate order; mapping.npz provides exact IDs. R candidates are39901.
All candidates are checked before one complete commit. No original H update
or teacher correction exists in this production path. a0 is the common saved
full initial state. Time input k*.005; output (k+1)*.005.

run creates new source-equation CPU Full references, a numerical Sham, a CNN
path and H-held controls. Original R/H equation and decoder weights are frozen.
The CNN path intentionally has a finite magnitude failure envelope of100.
The OFF180 failed run preserves399 actual steps and stops before step399

Use VALIDITY.json and committed_states.npy for that partial trajectory.

analyze reads Full truth only AFTER closed-loop execution. It saves all H/R
step errors, original331ROI E/M/Q/field-angle and fixed windows, and an offline

from this model's own-state production recursion.
