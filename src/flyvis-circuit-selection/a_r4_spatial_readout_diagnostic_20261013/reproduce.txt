a_r4 local-motion readout diagnostic, 2026-10-13

Scope
This directory is a sealed CPU research experiment, not an FPGA or camera demo.
The existing neural model, initial states, sampler and old readout are read-only.
New readout fitting changes only the diagnostic output map. It does not train
the neural network or replace the previously accepted direction benchmark.

Environment
Python 3.14, NumPy 2.4.6, OpenCV 4.13.0 in this run. Matplotlib is used only for
scientific plots. Each neural campaign sets CPU BLAS/OpenMP threads to one.
Exact source/model/initial/readout pins are in PREREGISTRATION.json.

Reproduction
Preserve the original sibling directory a_r4_video_direction_20261013 intact.
Create a fresh sibling directory, e.g. a_r4_spatial_readout_reproduction_01.
Copy study.py, audit.py and plot_results.py into that fresh directory.
Run these commands in sequence from the fresh directory:

python -B study.py prepare
python -B study.py design
python -B study.py calibrate
python -B study.py test
python -B study.py analyze
python -B audit.py
python -B plot_results.py

prepare freezes code, cases, mapping, source hashes and criteria before neural
computation. design computes 54 movies in both models. calibrate fits only Full
design activity, freezes the shared readouts, and refuses to run after test
has begun. test computes 66 unseen movies in both models. analyze scores all
five predefined readouts; no automatic winner replaces the primary field488.
The sealed run directories and JSON files deliberately reject overwriting.
Do not remove the guard to rerun over accepted data. A failure is retained.

Data semantics
MP4: 224x224, 100 fps, two seconds. Sampled external brightness input: float32
[400,721] Full or [400,61] a_r4. Shared 5 ms causal zero-order hold.
Each model starts from its own frozen 200-step gray-adapted initial state.
Every step reads its own current state and commits one new complete state.
No Full activity or removed-neuron activity is supplied to a_r4.
READOUT_MAP.npz gives exact global/local IDs for the same 488 T4/T5 neurons.
activity488.npy: [400,488] Euler output states; states.npy: a_r4 [400,3865].
Full complete intermediate states are NOT retained, only matched activity488,
complete final_state.npy and the full-state hash chain in steps.jsonl.
input_meta.json records actual MP4 SHA, frame IDs, times and sampling policy.
features.npz contains the five predetermined feature branches.
PREDICTIONS.json/csv include every test prediction and every rejection.

Interpretation
The new five-position test has screen-fixed window centers independent of
direction. This is a different stimulus design from the previous P0 study's
perpendicular-to-direction window shifts. Do not pool scores across studies.
Only four unseen directions, one speed, contrast, size and timing are tested.
The two new vertical positions are outside the readout fitting set.
Feature dimension 488 with 48 design motion examples is deliberately a fixed
ridge diagnostic; failure is not proof that all direction information is absent.
Static and nonmoving edge appearance are output-task false-positive controls,
not a claim that biological T4/T5 neurons should have no flash response.
Scientific execution PASS is distinct from the functional gate result.
