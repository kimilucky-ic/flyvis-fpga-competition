## 本地 RTL 核对出的配置编码

在 `hardware/hdl/rtl/router/spike_router.v` 中，连接字宽为 `18 + NEURON_ID_WIDTH`；本设计神经元 ID 为 10 位，因此连接字 28 位，字段是 `valid[27] / excitatory[26] / weight[25:18] / delay[17:10] / destination[9:0]`。连接槽地址为 `source_id * 32 + fanout`；连接数通过地址高字节 `0x01`、低位 source ID 访问。`snn_config_regs.v` 中，写 `0x00` 选择 router，写 `0x04` 选择配置地址，写 `0x08` 才会触发实际配置数据写入；读回走 `0x0C`。因此此前 `rtr()` 的 `0x00/0x04/0x0C` 只选择/读回，并不写连接数据。

本地按该 RTL 格式解码的第二条连接为 source 0→neuron 1：`0x0D900001`（valid、兴奋、权重 100、延迟 0、目标 1）。该值已在上方记录的 2026-10-06 板测中写入、读回并参与级联验证。重启后仍必须先只读保存当前 source 256 与 source 0 的连接槽/连接数；不可把重启前的历史读数当作当前值。
