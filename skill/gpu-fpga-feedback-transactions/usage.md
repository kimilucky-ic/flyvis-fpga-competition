# 使用示例：GPU/PL旧态所有权与COMMIT/ACK事务

## 准备输入

提供目标任务、源版本/身份、工具/设备版本、输入与参考身份、已声明的阈值、首个错误或原始结果。未知字段保留为未知，不复制本项目的板卡地址、路径或hash当作新工程事实。

先读 [操作正文](skill.md) 的适用范围、前提和停止条件。此示例是本次补齐的可改写提示词，尚未被独立使用者验证为稳定提示词。

## 可直接改写的提示词

> 按当前后端契约列出old-state、候选、COMMIT、RELEASE、ACK及IN_DOUBT状态机。核实GPU-H更新禁用、真实PL输出进入下一步；给出超时、错误ACK和缺失日志屏障的停止检查，禁止自动重试或复位。

## 交付与判断

1. 输出目标身份、前置条件、编号步骤、原始输出/日志保存位置和事先约定的验收门限。
2. 使用 [记录模板](../templates/reuse_record.json)，把未执行项保留为NOT_RUN，逐项填预期、实测、首差异、失效条件及证据hash。
3. 正常、失败或未知都如实记录；只读已有文件可直接做。板卡连接/配置/复位/MMIO/DMA、GPU或耗时EDA运行须有当前明确范围。
4. 对照 [历史证据与不足](validation.md)。相同任务的历史结果不能自动变成这次执行的PASS。
